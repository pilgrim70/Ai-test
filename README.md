# AI 사역도구

설교 원고 하나로 한 주 사역 자료와 설교 쇼츠를 자동 생성하는 목회자 전용 AI 사역 지원 플랫폼입니다.

## 주요 기능
- **설교 요약 및 개요 자동 생성**
- **소그룹 나눔 질문지 생성**
- **주간 QT (6일치) 묵상집 구성**
- **카드뉴스 이미지 기획 및 텍스트 자동 추출**
- **9:16 모바일 설교 쇼츠 영상 및 자막(SRT) 생성**
- **세대별(장년/청년/전체) 맞춤 톤앤매너 변환**

## 파일 구성
- `index.html`: 메인 랜딩 페이지 및 웹 애플리케이션
- `sermon-ai.html`: 원본 호환 파일

## 실행 방법
- 웹 브라우저에서 `index.html` 파일을 직접 열거나, 로컬 웹서버(`python3 -m http.server` 등)를 통해 바로 실행할 수 있습니다.
